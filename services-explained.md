# Azure services explained

- **Resource group**: a logical container used to organise related Azure resources.
- **Virtual Network (VNet)**: provides a private network boundary for resources.
- **Subnet**: divides a VNet into smaller network segments.
- **Network Security Group (NSG)**: allows or denies network traffic using rules.
- **Virtual Machine (VM)**: a computer running in Azure; this project plans Ubuntu and Nginx.
- **Storage Account**: provides Azure storage services; this project uses Blob Storage for files and backups.
- **Microsoft Entra ID**: manages identities and authentication.
- **Azure RBAC**: controls what an identity can do at a particular scope.
- **Azure Monitor**: collects metrics and supports alerts and diagnostic analysis.
- **Bicep**: declarative language for describing Azure resources as code.
